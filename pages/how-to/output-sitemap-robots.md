Cecil automatically generates `/sitemap.xml` and `/robots.txt`: they are [default pages](/documentation/configuration/pages/#pages-default) rendered with the built-in templates `_default/sitemap.xml.twig` and `_default/robots.txt.twig`.

## How it works

The two pages are declared in the default configuration:

```yaml
pages:
  default:
    robots:
      path: robots
      layout: robots
      output: txt
    sitemap:
      path: sitemap
      layout: sitemap
      output: xml
      changefreq: monthly
      priority: 0.5
```

- the **sitemap** lists all showable pages (published, not virtual, not redirected, not excluded), with their translations;
- **robots.txt** allows everything, disallows redirect pages and the 404 page, and points to the sitemap.

:::important
Set [`baseurl`](/documentation/configuration/site/#baseurl) in `cecil.yml`: both files use absolute URLs.
:::

## Exclude a page from the sitemap

Add [`excluded`](/documentation/content/front-matter/#excluded) to the page front matter:

```yaml
---
title: Thank you
excluded: true
---
```

The page is still published, but hidden from the sitemap and from list pages (home page, sections, etc.). Use `published: false` to not publish it at all.

## Change the default frequency and priority

```yaml
pages:
  default:
    sitemap:
      changefreq: weekly
      priority: 0.8
```

You can also set them per page, in the front matter:

```yaml
---
title: News
sitemap:
  changefreq: daily
  priority: 0.9
---
```

:::info
Pages with a custom canonical URL (`canonical.url` in the front matter) are not listed in the sitemap.
:::

## Add rules to robots.txt

Create a `pages/robots.md` page: its body is appended to the generated rules. As it replaces the default `robots` page, set `excluded: true` to keep it out of the sitemap and list pages.

```markdown
---
layout: robots
excluded: true
output: txt
---
User-agent: GPTBot
Disallow: /
```

## Override the templates

Extract the [built-in templates](/documentation/templates/lookup-rules/#built-in-templates) to start from the originals:

```bash
php cecil.phar util:templates:extract
```

Or create `layouts/sitemap.xml.twig` (or `layouts/robots.txt.twig`) from scratch. For example, a sitemap that also skips pages with a custom `sitemap_exclude` front matter variable:

```twig
<?xml version="1.0" encoding="utf-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  {%- for p in site.pages.showable|filter(p => not p.sitemap_exclude|default(false))|sort_by_date ~%}
  <url>
    <loc>{{ url(p, {canonical: true}) }}</loc>
    <lastmod>{{ p.date|date('Y-m-d') }}</lastmod>
  </url>
  {%- endfor ~%}
</urlset>
```

:::tip
To disable one of these files, unpublish its default page:

```yaml
pages:
  default:
    sitemap:
      published: false
```

:::
